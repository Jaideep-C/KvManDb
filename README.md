# KVMan DB

KVMan DB is a lightweight, high-performance key-value store database written in Java. This project was created as a learning exercise to understand database internals, concurrent programming, and Java systems design.

## Features

- Simple key-value storage interface
- Fast in-memory operations
- Persistent storage to disk
- Thread-safe concurrent access
- Basic CRUD operations (Create, Read, Update, Delete)
- Support for multiple data types
- Configurable storage options

## Learning Objectives

This project was built to learn and understand:
- Database architecture and design patterns
- Concurrent programming in Java
- File I/O and persistence strategies
- Memory management and caching
- Thread safety and synchronization
- Performance optimization techniques
